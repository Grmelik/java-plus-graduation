# ExploreWithMe 🔍

## О проекте
**ExploreWithMe** - это приложение, который позволяет пользователям делиться информацией об интересных событиях и находить компанию для участия в них. 
Приложение представляет собой афишу. В этой афише можно предложить какое-либо событие от выставки до похода в кино и собрать компанию для участия в нём. Пользователи могут оставлять комментарии.
В приложении есть рекомендательная система для предоставления пользователям помощи в нахождении интересующего их контента.

Приложение реализовано в виде микросервисов, которые реализуют пользовательскую и административную части.

## Архитектура
Приложение состоит из следующих компонентов:

### Инфраструктурные компоненты
* **Discovery Server (Eureka)**: регистрирует микросервисы для динамического нахождения друг друга. Запускается на порту 8761.
* **Config Server**: управляет конфигурациями микросервисов.
* **Gateway Server**: шлюз для маршрутизации внешних запросов к сервисам, использует Eureka для маршрутизации по именам сервисов. Запускается на порту 8080.

### Микросервисы

* **User Service**: административный сервис для управления пользователями (создание, удаление, получение списков).
* **Event Service**: сервис для управления событиями, категориями,подборками и локацией.
* **Request Service**: сервис обработкий запросов на участие в событиях (создание, отмена, подтверждение/отклонение).
* **Comment Service**: сервис управления комментариями пользователей.

### Сервисы статистики
* **Collector**: принимает сообщения о действиях пользователей, используя gRPC, и записывает полученные данные в Kafka-топик.
* **Agreggator**: выполняет анализ данных о действиях пользователей, рассчитывает ключевые метрики и сохраняет результаты в Kafka для последующей обработки.
* **Analyzer**: предоставляет рекомендации мероприятий пользователям

---

## Взаимодействие между сервисами

- **обнаружение сервисов**: все сервисы регистрируются в Eureka
- **конфигурация**: через Config Server, каждый сервис импортирует конфиг с `spring.config.import=configserver:`
- **внутреннее взаимодействие**: через Feign-клиенты
- **внешнее взаимодействие**: через API Gateway для маршрутизации внешних запросов к соответствующим сервисам
- **база данных**: каждый сервис имеет свою базу данных на основе PostgreSQL

## Фича
В качестве фичи были выбраны комментарии. Максиимальная длина составляет 1000 знаков. Создавать/редактировать/удалять комментарий может авторизованный пользователь, не являющийся автором мероприятия. Администратор модерирует комментарии перед публикацией. Информация о самом проекте и его эдпоинтах представлена ниже.

### **Эндпоинты фичи**

| Метод  | Путь                                 | Описание                    |
| ------ | :----------------------------------- | --------------------------- |
| POST   | /users/{userId}/comments             | Создать пользовательский комментарий         |
| DELETE | /users/{userId}/comments/{commentId} | Удалить пользовательский комментарий         |
| PATCH  | /users/{userId}/comments/{commentId} | Отредактировать пользовательский комментарий |
| DELETE | /admin/comments/{commentId}          | Удалить комментарий пользователя        |
| PATCH  | /admin/comments/{commentId}          | Отредактировать комментарий пользователя |
| GET    | /admin/comments                      | Получить все комментарии        |

## Конфигурация

Все конфигурации для микросервисов хранятся централизованно в **Config Server**. Взаимодействие настроено через Spring Cloud Config, который обеспечивает динамическое получение конфигурации.

## Тестирование
В случае локального тестирования (на локальном компьютере) надо добавить в application.yaml каждого микросервиса настройки:

eureka.instance.prefer-ip-address: true     # используем IP вместо hostname

eureka.instance.ip-address: 127.0.0.1       # явно указываем IP
