# ExploreWithMe 🔍

## Фича
В качестве фичи были выбраны комментарии. Максиимальная длина составляет 1000 знаков. Создавать/редактировать/удалять комментарий может авторизованный пользователь, не являющийся автором мероприятия. Администратор модерирует комментарии перед публикацией. Информация о самом проекте и его эдпоинтах представлена ниже. 

### **Эндпоинты фичи**

| Метод  | Путь                                 | Описание                    |
| ------ | :----------------------------------- | --------------------------- |
| POST   | /users/{userId}/comments             | Создать пользовательский комментарий         |
| DELETE | /users/{userId}/comments/{commentId} | Удалить пользовательский комментарий         |
| PATCH  | /users/{userId}/comments/{commentId} | Отредактировать пользовательский комментарий |
| DELETE | /admin/comments/{commentId}          | Удалить комментарий пользователя        |
| PATCH  | /admin/comments/{commentId}          | Отредактировать комментарий пользователя |
| GET    | /admin/comments                      | Получить все комментарии        |
---

## О проекте
**ExploreWithMe** - это приложение, который позволяет пользователям делиться информацией об интересных событиях и находить компанию для участия в них. 
Приложение представляет собой афишу. В этой афише можно предложить какое-либо событие от выставки до похода в кино и собрать компанию для участия в нём.
<img width="2880" height="1500" alt="image" src="https://github.com/user-attachments/assets/2125c577-5dee-4605-960c-75db73c0aec0" />

В приложении используются два сервиса:
- основной сервис содержит всё необходимое для работы продукта;
- сервис статистики хранит количество просмотров и позволяет делать различные выборки для анализа работы приложения.

## Основной сервис

API основного сервиса разделен на три части:
- **публичная** доступна без регистрации любому пользователю сети;
- **закрытая** доступна только авторизованным пользователям;
- **административная** — для администраторов сервиса.

В публичной части представлены следующие эндпоинты:

### События (Events)

| Метод | Путь              | Описание                          |
| ----- | :---------------- | --------------------------------- |
| GET   | /events           | Получить все события              |
| GET   | /events/{eventId} | Получить полное событие по его ID |
### Подборки (Compilations)

| Метод | Путь                   | Описание                   |
| ----- | :--------------------- | -------------------------- |
| GET   | /compilations          | Получить все подборки      |
| GET   | /compilations/{compId} | Получить подборку по ее ID |
### Категории (Categories)

| Метод | Путь                | Описание                    |
| ----- | :------------------ | --------------------------- |
| GET   | /categories         | Получить все категории      |
| GET   | /categories/{catId} | Получить категорию по ее ID |

В закрытой части представлены следующие эндпоинты:
### Заявки (Requests)

| Метод | Путь                                        | Описание                                             |
| ----- | :------------------------------------------ | ---------------------------------------------------- |
| GET   | /users/{userId}/requests                    | Получить все заявки по ID пользователя               |
| POST  | /users/{userId}/requests                    | Создать заявку пользователя на участие в мероприятии |
| PATCH | /users/{userId}/requests/{requestId}/cancel | Отменить заявку пользователя                         |
### События (Events)

| Метод | Путь                                      | Описание                                             |
| ----- | :---------------------------------------- | ---------------------------------------------------- |
| GET   | /users/{userId}/events                    | Получить все события по ID пользователя              |
| POST  | /users/{userId}/events                    | Создать новое событие                                |
| GET   | /users/{userId}/events/{eventId}          | Получение полной информации о событии                |
| PATCH | /users/{userId}/events/{eventId}          | Изменить событие                                     |
| GET   | /users/{userId}/events/{eventId}/requests | Получение информации о запросах на участие в событии |
| PATCH | /users/{userId}/events/{eventId}/requests | Изменение статуса заявок на участие в событии        |
### Комментарии (Comments)

| Метод  | Путь                                 | Описание                    |

| PATCH  | /users/{userId}/comments/{commentId} | Отредактировать комментарий |
